## 功能说明

### 行程总览
- 手绘风格大环线路线图（含山脉标注）
- 成都 ↔ 广州航班信息
- 每晚住宿海拔变化柱状图

### 每日行程（8天）
- **天气信息**：温度 + 天气图标
- **时间线**：上午 / 下午 / 傍晚
- **住宿信息卡**：可填写酒店名称 + 房型
- **餐饮 / 驾驶 / 提示**
- **旅行攻略链接**：粘贴自动解析，可点击跳转
- **今日喜爱程度**：1-5 星评分
- **旅行照片**：本地上传，支持删除
- **旅行笔记**：自由记录

### 出行准备
- 31 项清单，6 大分类
- 勾选跟踪进度，自动保存

### 行程记账
- 按类别记录花费
- 实时统计总额和分类占比

### 数据管理
- **导出全部数据**：下载 JSON 备份文件
- **导入数据**：从 JSON 恢复
- **清空数据**：重置所有记录

### 一键展开/收起
- 每日行程右上角按钮，一键展开或收起全部 8 天

## 数据说明

所有个人数据（照片、评分、笔记、酒店、攻略链接、记账、清单勾选状态）都存储在**浏览器本地（localStorage）**，不会上传到任何服务器。

**换设备或清缓存会丢失数据！**

**备份方法**：
1. 打开网页，滚动到底部「数据管理」区域
2. 点击「导出全部数据」，保存 JSON 文件到手机/电脑
3. 换设备后点击「导入数据」选择该文件恢复

## 部署到 GitHub Pages（详细步骤）

### 第一步：注册/登录 GitHub

1. 打开 [github.com](https://github.com)
2. 注册账号（如果还没有）
3. 登录

### 第二步：创建新仓库

1. 点击右上角 **+** 按钮 → **New repository**
2. 填写信息：
   - **Repository name**：`western-sichuan-trip`（或你喜欢的名字，只能英文）
   - **Description**（可选）：川西格聂大环线行程分享
   - **Visibility**：选择 **Public**（必须公开才能用 Pages）
   - 不要勾选 README、.gitignore 等
3. 点击页面底部的 **Create repository**

### 第三步：上传文件

在新创建的仓库页面，找到 **uploading an existing file** 链接，点击进入上传页面。

把本文件夹里的所有内容拖到上传区域：
```
github-pages/
├── index.html          ← 必须上传
├── hero-bg.jpg         ← 必须上传
├── route.kml           ← 必须上传
├── README.md           ← 可选
└── assets/             ← 整个文件夹上传
    ├── index-xxx.js
    └── index-xxx.css
```

> 注意：直接拖文件夹可能不支持，建议进入 `assets` 文件夹，把里面的 `index-xxx.js` 和 `index-xxx.css` 也一并拖上去。或者使用下方命令行方式。

**替代方案：命令行上传（推荐）**

```bash
# 1. 克隆仓库（把命令里的 你的用户名 和 仓库名 替换成实际的）
git clone https://github.com/你的用户名/仓库名.git
cd 仓库名

# 2. 把本文件夹所有文件复制进来
# （假设你把解压后的文件放在 western-sichuan-trip 文件夹里）
cp -r /path/to/github-pages/* .

# 3. 提交并推送
git add .
git commit -m "Initial upload"
git push origin main
```

### 第四步：开启 GitHub Pages

1. 在仓库页面，点击顶部菜单 **Settings**
2. 左侧边栏找到 **Pages**，点击进入
3. 在 "Build and deployment" 区域：
   - **Source**：选择 **Deploy from a branch**
   - **Branch**：选择 **main**，文件夹选择 **/(root)**
4. 点击 **Save**

等待约 1-2 分钟，页面会刷新，上方显示绿色提示：
```
Your site is live at https://你的用户名.github.io/仓库名/
```

### 第五步：访问并分享

1. 复制生成的链接
2. 发给朋友，或生成二维码分享
3. 在手机上打开，体验完整功能

## 常见问题

**Q: 链接打不开，显示 404？**  
A: 检查仓库是否是 Public（公开），且 Pages 设置里分支选的是 `main`。

**Q: 页面样式错乱，图片不显示？**  
A: 确认 `hero-bg.jpg` 和 `assets/` 文件夹里的文件都成功上传了。

**Q: 想更新网页内容怎么办？**  
A: 修改仓库里的文件（或重新上传），GitHub Pages 会自动重新部署，约 1-2 分钟后生效。

**Q: 可以绑定自己的域名吗？**  
A: 可以。在仓库 Pages 设置里可以添加自定义域名。

**Q: 朋友更新了攻略链接，我这边能看到吗？**  
A: **不能**。这是纯静态网页，所有数据存在各自浏览器本地。如需多人共享数据，需要额外开发后端。当前版本只能通过「导出 JSON → 发送给朋友 → 朋友导入」的方式分享数据。
